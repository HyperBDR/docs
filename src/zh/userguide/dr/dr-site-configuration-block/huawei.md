# **华为云(推荐使用，SDKv3.1.86)**

## **添加块存储**

通过顶部导航栏依次选择 **“配置管理” → “存储配置” → “块存储”** 进入块存储页面，点击右上角“添加”按钮，可进行块存储的新增配置操作。

### **鉴权信息**

块存储平台通过下拉列表选择“华为云(推荐使用，SDKv3.1.86)”，根据接入块存储的实际情况，填写以下平台鉴权信息：

> 若您不确定相关信息如何获取，可点击下方“点击查看”了解详细操作说明。<br>
> [👉 点击查看](https://qa.oneprocloud.com/questions/D1W2)

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-addblockstorage-1.png)

* **鉴权信息说明**

| **配置项**           | **示例值**                          | **说明**                                                                      |
| ----------------- | -------------------------------- | --------------------------------------------------------------------------- |
| 块存储平台 | 华为云(推荐使用，SDKv3.1.86) | 通过下拉列表选择块存储平台，此处选择华为云。推荐使用 SDK v3.1.86 版本。 |
| Access Key ID | HPUAAG0B2••••••••••••••• | 用于访问华为云 API 的身份凭证。登录华为云管理控制台，单击右上角“用户名”>“我的凭证”>“访问密钥”，获取 Access Key ID。 |
| Access Key Secret | •••••••••••••••••••••••••••••••• | 用于访问华为云 API 的身份凭证，与 Access Key ID 配合使用。登录华为云管理控制台，单击右上角“用户名”>“我的凭证”>“访问密钥”，获取 Access Key Secret。 |
| 区域 | cn-east-5 | 填写目标资源所在区域对应的项目名称。登录华为云管理控制台，单击右上角“用户名”>“我的凭证”>“API 凭证”，在“项目”中查看。注意：此处填写项目名称（例如：cn-north-1），而非项目 ID。 |
| 子项目 ID | ••••••••••••••••• | 填写子项目 ID。登录华为云管理控制台，单击右上角“用户名”>“我的凭证”>“API 凭证”，在“项目 ID”中查看。仅当项目包含子项目时需要填写，此项为非必填。 |
| 名称 | test | 自定义配置名称。如果不填写，系统将自动生成默认名称。 |

鉴权信息填写完毕后，点击“下一步”开始进行 **“资源配置”**。

### **资源配置**

为云同步网关分配计算、存储资源，确保其在目标环境中稳定高效运行。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-addblockstorage-2.png)

* **资源配置说明**

| **配置项**     | **示例值**                                   | **说明**                                                                                                                             |
|----------------|----------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| 区域           | 华东-青岛 | 已完成鉴权配置的目标区域，不可更改。 |
| 可用区         | 可用区1 | 通过下拉列表选择对应区域内的可用区。 |
| 实例规格        | 2 vCPU \| 4 GB | 通过下拉列表选择 vCPU 和内存规格，选择后自动刷新下方示例规格。具体以实际可选规格为准。云同步网关主要用于数据同步，建议选择至少 2 vCPU、4 GB 内存的实例，并确保基准带宽高于 1 Gbps，以保证数据同步效率和性能稳定。 |
| 镜像           | Ubuntu 24.04 | 通过下拉列表选择 Linux 操作系统镜像。创建云同步网关时，必须选择 Linux 操作系统镜像。如果列表中没有符合要求的镜像，请手动上传 Ubuntu 24.04 镜像。为避免镜像名称不规范导致误选，请仔细核对镜像信息，确保选择符合要求的操作系统镜像。 |
| 系统卷类型      | 高 IO | 根据实际存储性能需求选择合适的系统卷类型，具体以目标云平台支持的类型为准。 |
| 系统卷大小      | 40 GB | 用户可根据实例需求和云同步网关工作负载自定义。默认大小为 40 GB。 |

资源配置填写完毕后，点击“下一步”开始进行 **“网络配置”**。

### **网络配置**

为云同步网关分配网络资源，确保其在目标环境中稳定高效运行。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-addblockstorage-3.png)

* **网络配置说明**

| **配置项** | **示例值**                                                 | **说明**                                                                     |
| ------- | ------------------------------------------------------- | -------------------------------------------------------------------------- |
| 专有网络    | project-vpc (xxx.xxx.xxx.xxx/xx)                        | 通过下拉列表选择云同步网关所属的私有网络，具体以实际为准                                               |
| 子网      | project-subnet-public1-cn-north-1a (xxx.xxx.xxx.xxx/xx) | 通过下拉列表选择所属可用区中的子网，具体以实际为准                                                  |

* **网络高级设置**

| **配置项**         | **示例值**                                                                                                     | **说明**                                                                                                               |
|--------------------|---------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------|
| 云同步网关控制网络   | 内网 | 设置控制台与云同步网关之间的控制指令下发网络。使用 VPN 或专线时，建议选择内网。 |
| 自定义控制网络      | example.com | 默认无需配置。仅在需要按指定地址连接时配置，例如 NAT 地址转换场景。支持 IPv4、IPv6 地址和域名。 |
| 数据传输网络       | 内网 | 设置源端与云同步网关之间的数据传输网络。使用 VPN 或专线时，建议选择内网。 |
| 自定义数据传输网络   | example.com | 默认无需配置。仅在需要按指定地址连接时配置，例如 NAT 地址转换场景。支持 IPv4、IPv6 地址和域名。 |

| 公网带宽          | 100 Mbps | 根据实际场景配置，支持 1–200 Mbps。该参数影响从源端到目标端的数据传输速率。 |

网络配置完毕后，点击“下一步”开始进行 **“目标启动设置”**。

### **目标启动设置**

用于配置目标端在恢复或演练过程中启动所需的关键参数，确保资源能够顺利接管与运行。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-addblockstorage-4.png)

* **目标启动设置说明**

| **配置项**             | **示例值**                                          | **说明**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|------------------------|-----------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Windows 过渡主机镜像 | Windows Server-2019-English-Full-Base-2025.05.15 | 用于系统启动适配与引导修复，确保实例在目标平台正常启动。请选择与示例版本兼容的 Windows Server 2019 64 位镜像。 |
| 镜像访问方式 | 默认 | 用于设置实例凭据注入方式。支持默认和自定义两种模式。如果目标云平台不支持 Cloud-init，无法自动注入用户名和密码，则必须选择自定义模式，手动设置可用的账号和密码。 |


目标启动设置完成后，点击“完成”，系统将开始自动创建云同步网关及过渡主机镜像。

### **查看详情**

点击块存储名称，可查看块存储的详细配置信息。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-block-storage-details.png)

#### 网关可用性

在“网关可用性”列中，点击“点击查看列表”，即可查看云同步网关列表。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-addblockstorage-5.png)

在对应主机的“状态”列中，点击“点击查看详情”，可查看任务创建过程中产生的详细日志，便于快速掌握执行状态和排查故障。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-gateway-task-details.png)

在对应主机的“健康状态”列中，点击“点击查看详情”，可查看当前网关的错误日志，便于快速掌握执行状态和排查故障。

> 当云同步网关运行正常时，不会显示“点击查看详情”按钮。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-gateway-availability-details.png)

##### 更多操作

选中单台云同步网关后，点击“更多操作”按钮展开更多操作菜单，可对云同步网关进行配置调整：

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-gateway-moreoperations.png)

###### 修改

点击“修改”，可对该云同步网关关联的 Windows 过渡主机镜像进行重新选择与调整。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-gateway-modify.png)

###### 修改网络高级设置

点击“修改网络高级设置”，可修改自定义控制网络与自定义数据传输网络的 IPv4/IPv6 地址或域名配置。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-gateway-modify-network.png)

###### 修改驱动适配网络方式

点击“修改驱动适配网络方式”，可切换驱动适配主机的网络连接方式。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-gateway-modify-driver.png)

###### 重试

当云同步网关未能成功构建时，点击“重试”重新构建云同步网关。

###### 删除

点击“删除”，系统将弹出删除二次确认窗口。若云同步网关中存在备份卷，需勾选确认强制删除。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-gateway-delete.png)

#### 过渡主机镜像

在“过渡主机镜像”列中，点击“查看”，即可查看过渡主机镜像构建过程中产生的详细日志，便于快速掌握执行状态和排查故障。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-transition-host-image-details.png)

在“过渡主机镜像”列中，点击“点击查看列表”，即可查看过渡主机镜像详细列表。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-transition-host-image-list.png)

## **制作过渡主机镜像**

当过渡主机镜像列提示“有新版本”时，勾选对应平台条目并点击顶部“制作过渡主机镜像”。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-build-transition-image.png)

## **检查镜像**

勾选对应平台条目，点击顶部“检查镜像”以校验镜像状态。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-check-image.png)

## **更多操作**

勾选目标平台后，点击“更多操作”下拉按钮展开管理操作菜单：

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-moreoperations-1.png)

### **修改**

点击“修改”，可对鉴权信息进行编辑操作。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-moreoperations-modify.png)

### **扩展**

点击“扩展”，可对资源配置、网络配置、目标启动设置进行修改编辑操作。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-moreoperations-2.png)

### **平台配置**

点击“平台配置”，可针对主机创建、磁盘创建、快照创建及镜像创建的超时时间进行自定义配置。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-moreoperations-platform-config.png)

### **报告导出**

点击“报告导出”，可导出对应云同步网关报告信息。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-moreoperations-3.png)

选择对应报告类型、采集范围、时区、时间范围后，点击“下一步”，选择需要导出报告的主机后点击“确认”。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-moreoperations-4.png)

### **删除**

点击“删除”，系统将弹出删除确认提示框，核对删除风险提示后点击“确认”，即可完成删除。

> **注意：** 当存在云同步网关时，无法删除存储平台，需先删除云同步网关后再执行删除。

![](./images/huaweicloud_recommendeduse_sdkv3_1_86-moreoperations-8.png)
